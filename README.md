پایگاه خبری، تحلیلی و مجله آنلاین جامع، واکنش‌گرا (Responsive)، همراه با **پنل مدیریت پیشرفته، دستیار تولید محتوای هوش مصنوعی Gemini، استودیو شخصی‌سازی قالب، دستیار سئوی ۵ مرحله‌ای (SEO Wizard)** و قابلیت مدیریت چندسطحی کاربران.

---

## 🌟 ویژگی‌های کلیدی پروژه (Key Features)

### 📰 ۱. بخش کاربری و پرتال خبری (Public News Portal)
- **طراحی مدرن و راست‌چین (RTL):** تایپوگرافی اصیل فارسی با فونت وزیرمتن، چیدمان منظم و بدون شلوغی با رعایت دقیق قوانین UX/UI.
- **تقویم و تاریخ شمسی:** نمایش تاریخ روز شمسی و نوار اطلاع‌رسانی بالای سایت.
- **جستجوی پیشرفته و فیلتر دسته‌بندی‌ها:** امکان فیلتر لحظه‌ای اخبار بر اساس دسته‌بندی، کلیدواژه‌ها و برچسب‌ها.
- **حالت شب و روز (Dark/Light Mode):** تغییر پویا و روان درون‌مایه‌ی تاریک و روشن با حفظ کنتراست استاندارد WCAG.
- **نشان‌کردن اخبار (Bookmarks):** ذخیره‌سازی محلی اخبار موردعلاقه کاربر جهت مطالعه بعدی بدون نیاز به اینترنت.
- **سیستم دیدگاه‌ها:** ارسال نظرات کاربران همراه با پاسخ‌دهی لایه‌ای و تایید مدیر.
- **تبلیغات بومی (Ad Banners):** جایگاه‌های ویژه تبلیغات متنی و بنری در هدر، میان محتوا و لای اوت.

---

### 🎨 ۲. استودیو شخصی‌سازی قالب (Personalization Studio)
- **مدیریت تم و رنگ‌بندی آنلاین:** تغییر رنگ اصلی (Primary) و رنگ آکسان (Accent) بدون نیاز به کدنویسی.
- **انتخاب فونت و شعار سایت:** تنظیم نام پایگاه خبری، شعار، لوگو، ای آیکون و شعارهای زیرعنوان.
- **مدیریت شعاع انحنای کارت‌ها (Border Radius):** شخصی‌سازی انحنای دکمه‌ها و باکس‌ها.
- **مدیریت عناصر هدر و فوتر:** نمایش/مخفی‌سازی نوار تاریخ، دکمه‌های جستجو، حساب کاربری و لینک‌های تماس.
- **شبکه‌های اجتماعی و ارتباط با ما:** تنظیم هوشمند لینک‌های تلگرام، اینستاگرام، توییتر، بله، واتس‌اپ، یوتیوب، تلفن و ایمیل با قابلیت مخفی‌سازی خودکار فیلدهای خالی.

---

### 🚀 ۳. دستیار هوشمند سئو و بهینه‌سازی (SEO Wizard Studio)
یک سامانه ۵ مرحله‌ای گام‌به‌گام برای بهینه‌سازی کامل سایت جهت کسب رتبه‌های برتر گوگل:
1. **مرحله ۱ - متاتگ‌ها و عناوین:** تنظیم Title، Meta Description و کلمات کلیدی به همراه **پیش‌نمایش زنده نتايج گوگل (Google Search Snippet Preview)**.
2. **مرحله ۲ - پروتکل Open Graph:** تنظیم کارت‌های اشتراک‌گذاری برای تلگرام، واتس‌اپ و توییتر (OG Title, OG Image, OG Description).
3. **مرحله ۳ - فایل‌های Robots.txt و Sitemap.xml:** ویرایشگر زنده فایل ربات‌ها و تولید خودکار نقشه سایت XML برای اخبار.
4. **مرحله ۴ - داده‌های ساختاریافته (JSON-LD Schema.org):** اسکیمای خودکار `NewsArticle` و `NewsMediaOrganization` جهت حضور در Google News.
5. **مرحله ۵ - چک‌لیست سلامت و امتیاز سئو:** آنالیز زنده شاخص‌ها با امتیاز از ۱۰۰ به همراه **دکمه اصلاح یک‌کلیکه و هوشمند تمام خطاهای سئو**.

---

### 🤖 ۴. دستیار نگارش خبر با هوش مصنوعی Gemini
- نگارش و تولید اخبار و مقالات تخصصی با هوش مصنوعی.
- خلاصه‌سازی خودکار متون طولانی و استخراج کلمات کلیدی و تیترهای جذاب.
- بازنویسی و تنظیم لحن خبری (رسمی، تحلیلی، فوری).

---

### 📱 ۵. پایش و ایمپورت از پیام‌رسان‌ها (Messenger Integration)
- قابلیت پایش و دریافت کانال‌ها و گروه‌های تلگرام، بله و واتس‌اپ.
- تبدیل خودکار پیام‌های پیام‌رسان‌ها به پست‌های خبری پیش‌نویس با یک کلیک.

---

### 🔐 ۶. سطوح دسترسی و مدیریت کاربران (Role-based Auth)
- **مدیر کل (Admin):** دسترسی کامل به تنظیمات، سئو، شخصی‌سازی، اخبار، نظرات و آمار.
- **نویسنده (Author):** ارسال و ویرایش مقالات خود و دسترسی به دستیار هوش مصنوعی.
- **کاربر معمولی (User):** امکان ثبت‌نام، ذخیره اخبار و ارسال دیدگاه.
- **ورود سریع آزمایشی (Demo Quick Login):** امکان تست فوری تمام نقش‌ها بدون نیاز به رمز عبور.

## 💻 راه اندازی و اجرا (Getting Started)

### پیش‌نیازها
- نصب [Node.js](https://nodejs.org/) (نسخه ۱۸ یا بالاتر)
- مدیریت پکیج `npm` یا `yarn`

### ۱. کلون کردن مخزن (Clone Repository)
```bash
git clone https://github.com/your-username/khabar-online-portal.git
cd khabar-online-portal
```

### ۲. نصب پکیج‌ها (Install Dependencies)
```bash
npm install
```

### ۳. تنظیم متغیرهای محیطی (Environment Variables)
یک فایل `.env` در ریشه پروژه بسازید و کلید Gemini را در صورت نیاز اضافه کنید:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### ۴. اجرای دستور توسعه (Run Dev Server)
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس خواهد بود.
